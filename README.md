# 平视

特殊人群科普网站，网址：https://zzzopb.github.io

## 文件说明（不用懂代码也能看）

- `_posts/`：所有文章。每篇是一个 `.md` 文件，文件名格式是 `日期-英文短名.md`
- `_config.yml`：网站名字、栏目列表。新栏目上线时，把对应栏目的 `live` 改成 `true`
- `vision/`：视障栏目的目录页。新栏目上线时，复制一份改名
- `about.md`：关于页面
- `WRITING_GUIDE.md`：写作规范，每篇新文章都按这个来

## 怎么改一篇文章

在 GitHub 网页上点开 `_posts/` 里的文章 → 右上角铅笔图标 → 直接改 → 页面底部点 **Commit changes**。一两分钟后网站会自动更新。
