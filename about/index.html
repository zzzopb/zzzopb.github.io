关于「平视」

「平视」是一个个人维护的科普网站，介绍多元的群体和不同的人。名字的意思是：不俯视，不仰视，平等地看待彼此。

很多误解，来自”不了解”。我们希望用通俗的语言，把不同人群的真实处境讲清楚：他们是谁，常被怎样误解，日常怎么生活，我们又能怎样相处。

目前已上线的栏目是视障，听障、自闭症、阿尔茨海默症、肢体障碍、罕见病等栏目正在筹备，会陆续更新。

说明

本站希望帮助更多人了解不同的群体，内容仅供科普参考，不能代替医疗或专业建议。

我们相信，最大的尊重不是特殊的同情，而是把对方当作一个平等的、独立的人：先看到这个人，再看到他的不同。需要帮助时，先询问、听对方的意见，而不是替对方做决定。

我们怎么写

准确 涉及医学、数据、法律的内容，尽量引用权威来源，比如世界卫生组织、国家标准、法律原文、主流媒体报道和学术研究。每篇文章末尾都列出出处，方便你核对。

尊重 我们尽量使用当事人群体更认可的说法。比如：

尽量避免 我们使用
瞎子 盲人、视障者、视障人士
残废 残障、残疾
正常人（和残障者对比时） 普通人、非残障人士
特殊人群 不同的人、多元群体
身残志坚、可怜 平实地描述，不刻意煽情

不同群体、不同个人的偏好并不完全一样。比如很多盲人自己就直接说”盲人”，全国性组织也叫”中国盲人协会”。我们会持续学习、调整。

听当事人的声音 残障运动里有一句话：”没有我们的参与，不要做关于我们的决定。”我们希望以后能更多地引用当事人自己的讲述。如果你愿意分享经历，欢迎联系。

不是什么

  • 不是医疗建议。身体不适，请找专业医生。
  • 不代表任何机构。这是一个个人项目。

纠错与建议

写错了、说法不妥、有更好的资料？非常欢迎指出。你可以发邮件到 pingshi2026@163.com，或者在 GitHub 上留言，我们会尽快核实、修改，并在文章里注明更新日期。

无障碍

这个网站本身也在尽量做到无障碍：

  • 右上角可以放大字号、切换高对比度配色
  • 跟随系统自动切换深色模式
  • 可以只用键盘浏览，页面最上方有”跳到正文”的链接
  • 尽量使用清楚的标题层级，方便读屏软件导航

如果你在使用中遇到障碍，请告诉我们。
